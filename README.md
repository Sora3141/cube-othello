# キューブ・オセロ — 立方体の6面で遊ぶオセロ

立方体の6つの面すべてを盤面にしたオセロ。縦と横の列は辺を越えて隣の面へつながり、立方体を一周します。

## 🔗 リンク

- 遊ぶ: https://sora3141.github.io/cube-othello/
- 制作: [T.OFO](https://sora3141.github.io/)

## 遊び方

### ルール
- 基本は通常のオセロ。相手の石をはさむと裏返る
- 縦・横の列は辺を越えて隣の面へ続く（立方体を一周する輪）
- 斜めの列は同じ面の中だけ
- 置ける場所がなければ自動でパス。両者置けなくなったら終局

### 機能
- CPU 対戦（やさしい / ふつう / つよい）・ふたり対戦
- 盤の大きさ 2×2×2 / 4×4×4 / 6×6×6
- 展開図（6面を一覧でき、そこからも石を置ける）
- 置く前に裏返る石をプレビュー、一手戻す、対局の自動保存

### 操作
ドラッグで回転、クリックで配置（タッチは2回タップ）、ホイール / ピンチでズーム。
`← → ↑ ↓` で90°回転、`Space` で視点リセット、`⌘/Ctrl+Z` で一手戻す。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: メニュー画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

一度開けば、オフラインでも遊べます（three.js もサービスワーカーが保存します）。

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

## Files
- `index.html` — アプリ本体（three.js を CDN から読み込み）
- `sw.js` — オフライン用のサービスワーカー（three.js の版を変えたら `LIBS` もそろえる）
- `manifest.webmanifest`, `icons/` — PWA の設定とアイコン
- `webapp-kit/` — 「アプリにする」「共有」ボタン（正本は [sora3141.github.io](https://github.com/Sora3141/sora3141.github.io) の `webapp-kit/`）

設定・対局は端末の `localStorage`（`cube-othello.` で始まるキー）に保存します。
